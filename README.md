## 🔍 What is AegisCLI?

Modern security workflows require many different tools. Instead of juggling them, AegisCLI gives you one unified CLI with a numbered menu, consistent output, tool aliases, and a modular plugin system.

**Before — juggling multiple tools:**

```bash
nmap -sV -p 80,443 target.com
subfinder -d target.com
whois target.com
dnsrecon -d target.com
curl -I https://target.com
sslscan target.com
```

**After — one hub:**

```bash
python aegis.py
# → pick a tool by number, name, or alias
# → answer 2–3 prompts
# → get structured results
```

## ✨ Features

| Feature | Description |
|---|---|
| 🎨 **Modern UI** | Rich-powered terminal with animations and cohesive palette |
| 🚀 **Tool Aliases** | Run tools by number, full name, or short alias (`nm`, `ss`, `dr`) |

| 🎯 **Stable Contract** | Each tool exposes `run()`, `description`, `SCHEMA` |

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/novemixs/AegisCLI-NMS.git
cd AegisCLI-NMS

# Create a virtual environment
python -m venv .venv

# Activate (Windows)
.venv\Scripts\activate.bat

# Activate (Linux/macOS)
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Launch the Hub
python aegis.py
```

**requirements.txt**

```text
rich
cryptography
prompt-toolkit
python-whois
requests
dnspython
```

**Requirements:** Python 3.10+ · pip · Linux / macOS / Windows

> ⚠️ **Windows users:** Run in Windows Terminal or VS Code's integrated terminal for best results. Legacy `cmd.exe` may not render emoji/ANSI correctly.

## 🛠️ Usage

### Interactive Hub (recommended)

```bash
python aegis.py
```

| Command | What it does |
|---|---|
| `<number>` / `<name>` / `<alias>` | Run a tool (e.g. `1`, `nmap`, `nm`) |
| `info <tool>` | Show module details |
| `search <keyword>` | Find tools by name/description |
| `favorite <tool>` | Star / unstar a tool |
| `favlist` | List favorites |
| `history` | Show recent commands |
| `reload` | Hot-reload all tools |
| `set <key> <value>` | Change config |
| `config` | Show current config |
| `clear` | Clear screen |
| `help` | Show help panel |
| `exit` / `q` | Quit |

### Non-interactive / Scripting

Each module can also be run standalone with `--json`:

```bash
# Port scan with JSON output
python tools/nmap.py scanme.nmap.org --json > scan.json

# Subdomain enumeration
python tools/subfinder.py example.com --json -t 100

# Custom port range, no banner
python tools/nmap.py 127.0.0.1 -p 22,80,443,8080 --no-banner
```

## 🧩 Modules — Full Detail

<details>
<summary><b>🔍 Recon</b> — nmap · subfinder · whois · dnsrecon · httpx_probe</summary>

**nmap — TCP Port Scanner**
- Multi-threaded (`ThreadPoolExecutor`, default 200 workers)
- IPv4 and IPv6 via `getaddrinfo`
- 100+ common-service name map
- Best-effort banner grabbing (SSH, HTTP, FTP, SMTP…)

**subfinder — Subdomain Enumerator**
- Built-in ~250 common subdomain wordlist
- Custom wordlist support
- Per-lookup hard timeout (no hangs on dead DNS)

**whois — Domain Registration Lookup**
- Registrar · creation/expiry/updated dates
- Nameservers · domain status · contact emails
- DNSSEC status · DNS resolution to IPs

**dnsrecon — DNS Records Enumerator**
- A, AAAA, MX, TXT, NS, SOA, CNAME, SRV, CAA
- SPF detection
- Zone transfer (AXFR) attempts on each nameserver

**httpx_probe — HTTP/HTTPS Prober**
- Multi-host live detection
- Status codes · page titles
- Tech-stack detection (Nginx, Cloudflare, WordPress, React, etc.)

</details>

<details>
<summary><b>🌐 Web</b> — http_headers · dirbrute · sslscan</summary>

**http_headers — Security Headers Analyzer**
- HSTS · CSP · X-Frame-Options · Referrer-Policy
- Grade (A+ / A / B / C / D / F) with score
- Info-leak detection

**dirbrute — Directory Brute-Forcer**
- Built-in wordlist of 129+ common paths
- Custom wordlist & extension support
- False-positive size filter
- Status-code grouping with colored tables

**sslscan — SSL/TLS Scanner**
- Certificate details (CN, Org, Issuer, SAN)
- TLS versions (1.0, 1.1, 1.2, 1.3)
- Chain verification · expiry warnings
- Grade (A+ / A / B / C / D / F)

</details>

<details>
<summary><b>🔐 Cryptography</b> — hash · john</summary>

**hash — Hash Analyzer & Crypto**
- Identify: MD5, SHA-1/224/256/384/512, NTLM, bcrypt, sha512crypt, md5crypt
- Compute: MD5, SHA-1/224/256/384/512
- AES encrypt/decrypt via Fernet + PBKDF2

**john — John the Ripper Wrapper**
- Auto-detects vendored or system John
- Actions: `status`, `crack`, `show`, `list_formats`, `wordlist`
- Structured cracked-hash output

</details>

<details>
<summary><b>⚙️ System</b> — audit</summary>

**audit — System Security Auditor**
- World-writable file scan (Linux)
- Listening-services enumeration (Linux/Windows)
- Cross-platform dispatcher

</details>

## 🤝 Contributing

Contributions welcome — Python dev · security research · module development · tool integrations · AI engineering · docs · CLI/UX · testing.

```bash
git clone https://github.com/novemixs/AegisCLI-NMS.git
cd AegisCLI-NMS
git checkout -b feature/your-feature

# Make your changes

git add .
git commit -m "Add: your feature"
git push origin feature/your-feature
```

Then open a Pull Request.

Every module must expose:

```python
description = "Short description"
__version__ = "x.y"
__author__  = "Your Name"
__category__ = "Recon"          # Recon / Web / Cryptography / System
SCHEMA      = { ... }           # args manifest

def run(args: dict | None = None) -> dict:
    """Interactive if args is None. Return a structured dict."""
```

See existing modules in `tools/` for the reference pattern.
