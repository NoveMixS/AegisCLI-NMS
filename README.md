# AegisCLI (Network & Modular Security)

> A lightweight, open-source, and modular command-line interface (CLI) security toolkit built with Python.

---

## 🚀 Overview
**AegisCLI** is designed to streamline essential network reconnaissance, asset discovery, and system auditing tasks directly from the terminal. Built with a modular architecture, it allows developers and security enthusiasts to execute lightweight security checks efficiently without heavy system overhead.

---

## 🛠️ Planned Core Modules (Phase 1)
* **Network Reconnaissance:** Fast port scanning and active host detection.
* **Subdomain Enumeration:** Lightweight target discovery utility.
* **Hash Analyzer:** Local cryptographic hashing and identification utility.
* **System Security Auditor:** Basic permission and local misconfiguration checker.
